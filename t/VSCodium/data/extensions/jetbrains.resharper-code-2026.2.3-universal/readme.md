Whether you need a second pair of eyes or guardrails for code generated by AI, ReSharper fits seamlessly into your workflow – all backed by enterprise-grade security, SOC 2 compliance, and the trust of leading companies worldwide.

This powerful toolset will boost your productivity when developing in C#, XAML, Razor, and Blazor, with the powerful debugger, smart code analysis, precise refactorings, quick navigation, NuGet package management, and consistent formatting.

## Key features

The ReSharper extension offers a suite of productivity-enhancing features:

**🆕 Debugging** allows you to identify the true cause of a bug, beyond just where it crashes. You can pause your code precisely when an issue occurs using various types of breakpoints, such as conditional, hit-count, or dependent ones. By inspecting the live state and watched expressions, you get an accurate view of what the program is actually doing instead of relying solely on log outputs. You can step into and navigate through the call chain to trace the exact execution path, rather than assumptions. This debugging tool works with .NET, .NET Framework, and Mono, including capabilities to attach to running processes. It’s powered by the same engine that drives JetBrains Rider.<br>

## First steps

1. Install ReSharper from your preferred marketplace.
2. Open a workspace/folder in your VS Code-compatible editor.
3. ReSharper will automatically detect any `.sln`/`.slnx`/`.slnf` (solution) files or a `csproj` file in the folder:
* If only one solution is found, it will open automatically.
* If multiple solutions are found, click the *Open Solution* button in a popup menu to choose which one to open.


### Compatibility recommendation

ReSharper for Visual Studio Code includes code completion, code analysis, and quick fixes that may overlap with [Microsoft C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp) and [C# Dev Kit ](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit) extensions. To avoid confusion from overlapping features and to get the full ReSharper experience, we recommend disabling the Microsoft extensions while evaluating ReSharper.

Note that debugging is an exception: VS Code allows only one extension to be registered as the debug engine for C#. If another extension that provides C# debugging capabilities (for example, C# Dev Kit) is installed and enabled, the ReSharper debugger will not be available. To debug with ReSharper, disable or uninstall other C# debugging extensions and reload your editor. All other features can run alongside other extensions without technical limitations.
